# EIZ 业务数据查询 Skill

收到用户关于业务数据的查询需求时（如查客户、查订单、查物流等），按以下步骤执行：

## 可用工具

| 工具名称 | 用途 |
|---|---|
| `KB-db-wiki___Retrieve` | 数据库知识库检索：表结构、字段说明、索引、查询规范 |
| `KB-business-wiki___Retrieve` | 业务知识库检索：业务规则、状态码含义、业务流程 |
| `mysql-search_objects` | 搜索数据库对象（表、视图等） |
| `mysql-execute_sql` | 执行 SQL 查询（只读） |
| `CN_MCP_SERVCER-getCsvBySql` | **大数据量查询或导出需求**：生成 CSV 下载链接 |

## 第一步：从知识库获取规范

使用知识库检索工具按关键词查询相关内容：

### 1.1 数据库知识库（`KB-db-wiki___Retrieve`）

查询表结构、索引、查询规范等，关键词示例：
- `MySQL 查询规范 索引` — 获取大表规则、索引使用要求
- `表字段说明 索引` — 获取字段含义和索引字段
- `查询模板 SQL` — 获取标准查询写法

**注意：知识库只存储常用表的说明，不常用表不在知识库中，需通过 `SHOW CREATE TABLE` 或 `DESCRIBE` 直接查数据库获取结构。**

### 1.2 业务知识库（`KB-business-wiki___Retrieve`）

查询业务规则、状态码含义、业务流程等，关键词示例：
- `订单状态码` — 获取各状态码的业务含义
- `客户类型 分类` — 获取客户分类规则
- `物流流程 节点` — 获取物流业务流程

## 第二步：确认表结构（首次或不确定时）

使用 `mysql-search_objects` 和 `mysql-execute_sql` 执行：

```sql
DESCRIBE 表名;
SHOW INDEX FROM 表名;
```

确认字段名和索引后再写正式查询。

## 第三步：选择查询方式

### 3.1 小数据量查询（≤50 条）

使用 `mysql-execute_sql` 直接执行 SQL 查询。

### 3.2 大数据量查询或导出需求

**优先使用 `CN_MCP_SERVCER-getCsvBySql`**，生成 CSV 下载链接给用户。

适用场景：
- 用户明确要求"导出"、"下载"
- 预计结果超过 50 条
- 用户需要将数据导入 Excel 或其他系统

## 第四步：编写并执行查询

根据知识库规范编写 SQL。关键要求：

- **所有查询必须只读**（SELECT / SHOW / DESCRIBE）
- **WHERE 条件命中索引字段**，不确定时先 SHOW INDEX
- **大表禁止无条件全量扫描**：禁止 `COUNT(*)`、`SELECT *`、无 WHERE 的聚合查询，必须带 WHERE 条件且命中索引
- **明细查询带 LIMIT**（默认不超过 50 条）
- **大表不 JOIN**，拆成多步分步查询
- **时间范围用 `>=` 和 `<`**，不用 MONTH() / DATE() 包裹字段
- **结果展示**：状态码翻译成中文（从业务知识库查询），金额保留 2 位小数，时间格式化为 YYYY-MM-DD HH:mm
- **敏感信息脱敏**：email、phone 等字段用 CONCAT 做部分遮掩

## 第五步：呈现结果

用清晰易懂的中文向用户解释查询结果，必要时补充业务背景。

如果是 CSV 导出，将下载链接发给用户，并简要说明文件内容和行数。
