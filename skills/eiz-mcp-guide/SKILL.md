# EIZ Remote MCP 使用手册

本项目通过插件根目录的 `.mcp.json` 连接 EIZ Cloudflare Remote MCP：

`https://eiz-mcp.wangyii.org/mcp`

## 使用前提

1. 确认插件已经启用。
2. 第一次使用或提示未授权时，在 Claude Code 中运行 `/mcp`，完成 EIZ MCP 的 OAuth 授权。
3. 授权完成后，根据 MCP Server 和工具描述选择工具，不要假设旧的裸工具名称仍然有效。

## 工具选择原则

- 先使用工具搜索或 MCP Server 提供的工具说明，确认工具用途和参数。
- 只调用完成当前任务所需的最少工具。
- 涉及写入、发送、发布、删除或其他外部副作用的操作，先向用户说明影响并确认。
- 涉及业务数据时，优先获取相关业务说明、字段定义和查询限制，再执行数据操作。
- 不要在提示词、输出或代码中暴露 OAuth token、API key、数据库密码等凭据。
- 如果工具不可用，先检查 `/mcp` 中的连接和授权状态，再报告具体缺口；不要编造工具名或参数。

## 结果处理

- 保留 MCP 返回结果中的来源、时间范围和限制条件。
- 对敏感信息进行最小化展示和脱敏。
- 如果结果来自多个服务，明确区分每个服务的结论。
- 如果服务返回错误，原样保留必要的错误类型和非敏感信息，说明下一步需要的授权或参数。

## 工具命名说明

Claude Code 会为插件提供的 MCP 工具生成带命名空间的名称。实际可调用名称以当前会话中 MCP 返回的工具列表为准，不要直接使用其他客户端中的裸名称。
